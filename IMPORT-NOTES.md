## Replacing the test database later

The import is versioned as `test-stations-2-3-20261026-v1`. The app records its receipt in the student's synced state. Settings now has a reset action for the selected language. It requires confirmation, first downloads a backup of both languages, then clears only that language's words, lessons, hidden list, cycles and learning counters. It preserves catalogue receipts so the old test dataset does not reappear on the next load. Explicit manual imports remain possible; new catalogue batches use new IDs. No reset is executed by shipping this feature or importing the current dataset.
